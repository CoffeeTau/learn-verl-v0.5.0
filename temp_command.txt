### 检查 FlashAttention

verl 的 FSDP worker 会使用 FlashAttention：

python -c "import flash_attn; print(flash_attn.__version__)"

如果已经能导入，直接继续。否则先检查：

python -c "import sys,torch; print(sys.version); print(torch._C._GLIBCXX_USE_CXX11_ABI)"

如果是 Python 3.10、ABI 为 False，可以使用仓库安装脚本对应的预编译包：

curl -LO https://github.com/Dao-AILab/flash-attention/releases/download/v2.7.4.post1/flash_attn-2.7.4.post1+cu12torch2.6cxx11abiFALSE-cp310-cp310-linux_x86_64.whl

python -m pip install ./flash_attn-2.7.4.post1+cu12torch2.6cxx11abiFALSE-cp310-cp310-linux_x86_64.whl

如果不是 Python 3.10，不要安装这个 wheel；可以尝试：

MAX_JOBS=8 python -m pip install flash-attn==2.7.4.post1 --no-build-isolation

但源码编译会慢很多。
