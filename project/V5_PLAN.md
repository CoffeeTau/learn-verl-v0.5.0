## 唯一训练主干

| 项目 | 固定决策 |
|---|---|
| 初始化 | V4 main_20261007T095646Z_3f4cdb 的 step100导出权重；重建优化器，reference固定为该初始策略，不恢复V4 step125 |
| 检索与交互 | 冻结V3 E5/index；沿用V2输入和严格judge协议；统一token续接，无新增ledger、工具或长推理模板 |
| 数据 | 固定train2000：1500自然、250首次检索干预候选、250第二次检索干预候选。困难比例仍25%，仅扩展干预发生阶段 |
| 干预规则 | 复用withhold_one/related_distractors，每个阶段各125题；固定seed42与train-only计划。同题4个采样同一计划，每条轨迹最多干预一次；之后恢复正常检索 |
| 未触发处理 | 第二次搜索未发生，或返回未改变，记录未生效；不强迫多查、不替换为首次干预、不隐藏失败 |
| 奖励 | 沿用严格合法终局canonical F1，否则0；KL loss .001；不增加搜索惩罚、judge自述奖励或gold字符串覆盖奖励 |
| 资源 | 8卡，16题×4采样，lr1e-6，125更新上限；4次搜索、top3、每轮512token沿用已验证预算 |

第二次检索干预使“第一条关系已知、后续关系暂缺”出现在训练中；恢复检索后仍有最多两次搜索可用。自然样本保留正常结束行为。该组合并不保证修复目标漂移；终局奖励只提供间接监督，不宣称过程判断已获得正确标签。若关系链依然不稳，再考虑经过验证的train-only过程监督，不在本轮同时引入。

## 开发评测与选模

- step0及25/50/75/100/125：复用V4原自然200、原固定困难50及同50自然子集。开发困难规则仍为首次干预，不随训练课程修改；复制原计划并验证hash、ID、题目和gold一致。
- step0是本轮同部署基线；不能把独立80%硬当训练内最低值。模型候选的自然EM不得低于step0，自然协议失败数不得高于step0。
- 本轮目标预先改为困难鲁棒性：合格候选优先困难EM，再自然EM/F1、较低token、较早step；包含step0。困难EM无提升则不宣称鲁棒性升级。50题每题2pp，不据少量题差声称统计显著。
- 记录每阶段planned/applied调用、有效奖励差异比例、拒答/协议失败/EM/F1、搜索与token；不能用applied当恢复成功率。
- 最终所选checkpoint通过同一token续接独立评测；同口径比较V4，并保留所有失败题分母。自然性能、搜索/token成本与困难质量一起报告，不只挑最高分。
- 旧测试已参与讨论，本轮不再用来选模。新盲测另行冻结。
